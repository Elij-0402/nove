# 07: 写章：收稿、局部代笔、卷末结算

**What to build:** 补齐写章的另外两种模式和卷末动作。
- **收稿**：作者把自己写的章节放进正文目录，skill 负责回写状态、伏笔、摘要，然后送审。
- **局部代笔**：作者指定一段（「这场戏帮我写」「补一段过渡」「这段重写」），Claude 结合上下文只改这一段，不动其他内容。
- **卷末结算**：一卷写完时，把卷摘要压缩进全书摘要，并推进到下一卷卷纲关卡。
