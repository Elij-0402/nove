# 01: 指标脚本和测试

**What to build:** 作者把任意下载来的对标 txt（或新作的章节目录）交给指标脚本，得到一份确定性的 JSON 指标。内容包括：编码识别、剥掉站点杂质后的章节切分，以及每章和全书的字数、对白占比、句长和段长分布、高频词。拆书和审稿共用这一把尺子。只用 Python 标准库实现，放在拆书 skill 的 scripts 下。参见 spec「指标脚本」一节。
