# 设定

**开始前先按 [SETUP.md](../novel/SETUP.md) 确认技能目录、工作区、依赖和默认规范；同一轮已完成的准备可复用，失败就停下。**

按 `规范/模板/设定/` 给作品写设定，存进 `作品/<书名>/设定/`：一份模板对应一个同名的设定文件，默认是 `角色.md`、`世界观.md`、`势力.md`、`力量体系.md` 或 `关系体系.md`、`时间线.md`。自检后把项目.md 推进到「总纲 / 待开始」。

设定阶段没有关卡，做完就推进。要作者拍板的事记进自检，到总纲关卡一起看。

**设定只写事实和规则**：有谁、在哪、守什么规矩、开篇时是什么状态。谁在第几章做什么，关系哪一级升在哪章、秘密在哪章揭开，都归大纲。

## 1. 找作品

- **只做进度是「设定 / 待开始」的作品。** 作者点了名就用那一部，进度对不上就停下，把进度报给作者。没点名，找 `作品/*/项目.md` 里进度是「设定 / 待开始」的；有好几部就问作者。
- **`设定/` 下已经有文件，说明上次没做完**：读已有的，缺的补齐，不整套重写。

## 2. 读材料

- **项目.md 的基本信息和立项结论。** 设定和立项结论冲突时，以立项结论为准。
- **立项方案.md 里拍板的方案**：关卡日志写着拍的是哪个，有「最终方案」就读它；连同它的「主要风险」，和文末的「推荐」。
- **风格档案.md。**
- **`规范/模板/设定/` 下的全部模板。** 作者可能改过、加过模板，每次都现读。
- **主对标的 `对标库/<主对标>/拆书报告.md` 里「人设原型」「核心设定机制」两节，和同目录 `语义标注.json` 各章的「新角色」**：这些是要避开的具体形态和人名。主对标写在项目.md 的基本信息里。

读完把**交办**列成清单：上面读到的立项方案各节和风格档案里，凡是写着「设定阶段」的地方，都是交给设定做的一件事，比如新角色的口头禅、某类资料的核对表。

## 3. 选体系

- **力量体系和关系体系二选一，只写一份**：看主线靠什么往前走，对照两份模板开头写的适用情形。
- **没选的那一边如果也有硬规则，写进世界观的「主要规则」**，比如言情里的考核制度、玄幻里的婚约。

## 4. 写设定

- **结构照模板**：节、字段、栏和模板一一对应，顺序不变。「字段 | 内容说明 | 示例」这种字段表，写成一行一个「- 字段：内容」；别的表照表头写成表，一行一条。模板里的说明和示例不抄进设定。
- **立项结论写到的，设定里都要落地。** 一句话卖点、超越点，和差异清单每一行「新作」一栏里的角色、装置、舞台、规则，都要能在某个设定文件里找到。立项写死的结局和节点，写成设定要守的约束。
- **借功能，不借形态。** 对标的人物关系结构、配角组合、装置形态，新作一律重新设计。人名不和对标的「新角色」重名，也不同音。
- **角色卡**：立项结论写到的角色都建卡，之后会反复出场的配角也建；一次性的路人不建。每张卡的字段都写满，次要角色可以写短。
- **当前状态写开篇那一刻**，「截至」写「开篇」。
- **交办的事逐件落地。** 放得进某个设定文件的就放进去，比如口头禅进角色卡的「说话方式」；放不进的，在 `设定/` 下另起一个文件，用类别起名，比如 `病例.md`，开头写明它是哪件交办、出处在哪、写章和审稿怎么用。
- **说话方式过一遍风格档案**：「该作者不用的表达」里的词不用，「偶尔用」里的词不做口头禅。
- **真实世界的制度和知识要查实。** 行业规则、法规、医学、法律这类设定，用 WebSearch 查官方文件、学会指南或教材，出处写进「依据」；查不实的标【待查】。查实最慢，查回来的结果还可能动到设计：要查的条目一列出来，就分给几个子代理并行查，同时写不依赖它们的部分。
- **查实的规则和立项结论对不上时**，先在设定里找不违背立项的解法，比如补一条前提，记进待作者确认；找不到就原样报给作者，立项结论不改。

## 5. 自检

1. **派一个子代理自检**，任务书是 [CHECK.md](CHECK.md) 的全文，后面附上书名。它没参与写设定，只看纸面，更容易看出矛盾。
2. **它交回的问题逐条处理**：是矛盾就改设定；要作者拍板的，进待作者确认。
3. **按 [OUTPUTS.md](OUTPUTS.md) 写 `设定/自检.md`。**

## 6. 推进

- **项目.md 的进度改成「总纲 / 待开始」。** 备注写「设定自检有 N 件待作者确认、M 条待查，见 `设定/自检.md`」；两样都没有写「无」。
- **告诉作者**：生成了哪些文件；选了哪个体系、为什么；自检改了什么；待作者确认的事逐条列出，待查报条数；下一步是总纲（`/novel-dagang`），写完会停在总纲关卡。
