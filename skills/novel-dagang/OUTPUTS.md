# 大纲产物格式

总纲、卷纲、伏笔表的结构照 `规范/模板/大纲/`，这里只写 `大纲/自检.md`。

## 自检.md

`作品/<书名>/大纲/自检.md`，每次原创性自检追加一节，旧的不动。

```
# 《书名》大纲原创性自检

## 总纲（YYYY-MM-DD）
或者「第 N 卷卷纲（YYYY-MM-DD）」；关卡退回后改过再查的，标题后面加「复查」。

- 比对：大纲这边读了哪些文件；对标那边读了哪几份拆书报告
- 结果：发现 N 处重合，改了 N 处；没发现写「未发现重合」

| # | 类 | 对标 | 新作原来 | 改成 |
|---|---|---|---|---|

### 没改的
子代理报了、主代理判定不算重合的，每条写为什么。没有写「无」。

### 立项本身
子代理指出立项本身就像对标的地方，原样记下，关卡上报给作者。没有写「无」。
```

- **类照 CHECK.md 的五类。** 对标一栏写拆书报告的节名和原句摘要。
- **「新作原来」「改成」各写一两句**，改到哪个文件、哪一处写在「改成」里。
- **没发现重合时表格删掉**，结果一行写清查了哪五类、都没发现。
