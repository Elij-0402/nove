# 基线对比任务书

你负责把一部新作最近窗口的章节和主对标的基线并排比一比：机械指标用脚本量，语义指标你读正文标出来，都对照 `对标库/<主对标>/基线指标.md`。主代理会在这份任务书后面附上：书名、主对标名、窗口章节的章号范围和正文文件路径、每章目标字数。

**只量、只标、只比，不改任何文件。** 交回两张表加一段读法，改和拍板不归你。

运行路径遵循 [SETUP.md](../novel/SETUP.md)，沿用主代理传入的两根绝对路径和本轮准备结果；缺少或准备失败就停下报主代理，不自行铺文件。

## 读什么

- **`对标库/<主对标>/基线指标.md` 全文**：这是比对的基准。新作还在前期（窗口落在对标精拆范围覆盖的章数以内）就对照「精拆范围」那一列，已经写到中后期就对照「全书」列；拿不准对照精拆列，并在读法里说明。
- **窗口正文** `作品/<书名>/正文/NNNN-章名.md`：主代理给的那几章，逐章读，用来做语义标注。
- **标注口径读** `../novel-chaishu/CHUNK-BRIEF.md` 的「逐章标注」一节：情绪点、钩子、大高潮、新角色、高光照它的定义标，和拆书同一把尺子。

## 机械指标（脚本量）

在工作区根目录跑脚本，输出写系统临时目录、文件名带 `baseline` 免得和别的子代理撞：

- **单章窗口**直接量那一个文件：

  ```
  python "<技能目录>/novel-chaishu/scripts/metrics.py" "作品/<书名>/正文/NNNN-章名.md" -o "<临时目录>/baseline.json" --phrases "规范/套话候选.txt"
  ```

- **多章窗口**先把窗口那几章复制到一个临时目录，再量整个目录（脚本总是量整个目录）：

  ```
  python "<技能目录>/novel-chaishu/scripts/metrics.py" "<临时目录>/窗口" -o "<临时目录>/baseline.json" --phrases "规范/套话候选.txt"
  ```

读 `全书` 一节：字数、对白占比、章字数统计、句长统计、段长统计、高频词。数字照抄脚本原值，不心算、不取整。

**并排成一张表，新作窗口一列、对标基线一列**（比例和每万字频次才有可比性，别直接比总次数）：

| 机械指标【脚本】 | 新作窗口（第 X–Y 章）| 对标《书名》（精拆/全书）| 偏离 |
|---|---|---|---|

至少列：字数（窗口总字数、章均）、对白占比、章字数平均/中位、句长平均/中位/P90 和分布、段长平均/中位/P90 和分布、高频词前若干。「偏离」写「贴合 / 偏高 / 偏低」加一句幅度。

## 语义指标（读正文标 + 脚本算）

逐章按 CHUNK-BRIEF 的口径标情绪点、钩子、大高潮、新角色、高光，把这份标注写成一个临时的 `语义标注.json`（数组，每章一条 `{序号, 情绪点, 钩子, 大高潮, 新角色, 高光}`，和拆书那份同格式），再跑脚本算出各项，**别手算**：

```
python "<技能目录>/novel-chaishu/scripts/semantics.py" "<临时目录>/语义标注.json" --metrics "<临时目录>/baseline.json" -o "<临时目录>/semantics.json"
```

- `--metrics` 用你上一步量机械指标得到的那份窗口 JSON（`baseline.json`，脚本从里面取每章字数）。
- 各项口径见 [SEMANTICS.md](../novel-chaishu/SEMANTICS.md)，和拆书同一把尺；情绪点、大高潮、钩子、新角色、主角高光（含男女主分列）都在它的输出里。
- **窗口不足两章时间隔类会是 `null`，照实写「暂缺」，别硬算。**

把输出的 JSON 对照基线的语义指标（`基线指标.md` 的语义表，新作前期对精拆列），并排成第二张表：

| 语义指标【标注】 | 新作窗口 | 对标（精拆/全书）| 偏离 |
|---|---|---|---|

## 交付

两张表，后面附一段**读法**：

- **哪些贴合基线、哪些偏离**，偏离的说清是偏高还是偏低、幅度多大、可能的原因（能落到正文位置的落到位置）。
- **样本提醒**：窗口只有一两章时，情绪点、钩子、间隔这些语义数抖动大，明确写「样本小，看量级和结构，不抠个位数」；间隔类算不出的写「窗口不足，暂缺」。
- **不下达返修指令、不替作者拍板**：偏离是给作者在关卡上判断用的，你只报量和方向。
