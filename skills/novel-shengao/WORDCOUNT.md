# 字数审稿任务书

你负责量一部新作当前这一章的字数，看它贴不贴目标。主代理会在这份任务书后面附上书名、当前章的章号和正文文件路径。用脚本量，不靠估。

**只量、不改。** 交一张表回主代理。

运行路径遵循 [SETUP.md](../novel/SETUP.md)，沿用主代理传入的两根绝对路径和本轮准备结果；缺少或准备失败就停下报主代理，不自行铺文件。

## 读什么

- **`作品/<书名>/项目.md` 的基本信息**：「每章目标字数」那一个数。
- **正文**用脚本量，不用通读。在工作区根目录跑，输出写系统临时目录、文件名带 `wordcount` 免得和别的子代理撞：

  ```
  python "<技能目录>/novel-chaishu/scripts/metrics.py" "作品/<书名>/正文/NNNN-章名.md" -o "<临时目录>/wordcount.json"
  ```

  读 `全书.字数`（单文件时它就是本章字数）。

## 查什么

- **口径是脚本的字数**：非空白字符，标点算在内，标题行不算。和写章一个尺子。
- **目标区间是每章目标字数 ±15%。** 比如目标 3800，区间是 3230–4370（下限向下取整、上限向上取整）。
- **在区间里 → 通过；超上限 → 报超了多少、建议删多少；不到下限 → 报差多少、建议补多少。**

## 交付

一张表：

| 项 | 目标字数 | 目标区间（±15%） | 实际字数 | 结果 | 建议 |
|---|---|---|---|---|---|

- **结果写「通过」或「有问题」。**
- **建议**：超了写「删约 N 字」，不够写「补约 N 字」，通过写「—」。
