# 拆书子代理任务书

你负责拆一本对标网文的一段。主代理会在这份任务书后面附上：书名、题材、情绪点类型库初版、块号、类型（精拆或粗拆）、起止章和章节文件列表。章节文件在 `对标库/<书名>/章节/` 下，首行是 `# 标题`，之后每行一段。

**读完块里的每一章，一章都不能跳。** 产出只写**抽象层**：手法、结构、节奏、功能。原作的情节不复述，人名只在需要定位时出现。引用原文每处不超过 15 字，而且只用在「风格观察」里。

## 逐章标注（精拆和粗拆都要做）

块里每一章输出一条，放在一个 json 代码块里：

```json
[
  {"序号": 4, "情绪点": ["心动", "笑点"], "钩子": "情感悬停", "大高潮": false, "新角色": ["闺蜜:钟思乔"], "高光": ["女主"]}
]
```

- **情绪点**：这一章让读者产生明确情绪起伏的地方，每处记一次类型，同一类型出现两次就写两次。类型名用类型库初版里的，不要拿钩子的类型名来填；确实没有合适的，就新起一个，写成 `"新增:类型名"`。没有就写空数组。
- **钩子**：章末最后几段让读者想点下一章的手法，只能从这几个里选一个：`悬念`（抛出信息缺口）、`危机`（危险或冲突迫近）、`反转`（推翻刚建立的认知）、`情感悬停`（关系停在临界点）、`新信息`（新人物或新线索登场）、`期待`（约定或预告即将发生的事）、`平收`（没有钩子，自然收尾）。
- **大高潮**：这一章是一个剧情阶段情绪最高的地方（真相揭开、关系质变、大冲突爆发）时写 `true`。一个阶段通常只有一两个。
- **新角色**：这一章首次登场、之后还会反复出现的有名角色，每人记一条，写成 `功能定位:人名`。功能定位比如情敌、闺蜜、对手、长辈、同事。人名只用来让主代理跨块去重。你只看得到自己这一块，所以你块里第一次出现的角色都记上，前面块里是否出现过由主代理判断。一次性的路人不记。
- **高光**：主角（言情里是男女主）在这一章有展示能力、魅力或态度，让读者喜欢上他的场面，就记下是谁，写 `"男主"`、`"女主"` 或 `"主角"`。没有就写空数组。

## 精拆块还要写

- **情绪点铺垫手法**：每种出现过的情绪点类型，写它通常怎么被铺出来，比如提前多少章埋因、用什么反差、先抑后扬的节拍。每种附 1～2 个位置（章号），用来定位，不复述情节。
- **钩子手法**：这一块里最有效的几种章末写法。讲结构，比如「在对方开口前切断」，并附章号。
- **人设**：主要角色按功能定位写人设原型，包括表层性格与内核的反差、行为模式、和主角的关系张力。
- **核心设定**：这本书的金手指或核心设定（言情里常是把两人逼近的装置，比如同居、契约、失忆）在这一块里怎么被使用、怎么升级，附章号。
- **风格观察**：叙述视角和视角切换；描写、叙事、对白、心理四者大致的配比；标志性修辞，比如某种比喻习惯、句式节奏、幽默方式，每种附一个不超过 15 字的短例；作者明显不用的写法；角色的口头禅。
- **弱点**：读者可能跳读、出戏或吐槽的地方，比如拖沓、重复、逻辑硬伤、人设崩坏、节奏断档。每条都要写位置（章号，或者「第 N 章第 a–b 行」）、表现，以及读者为什么不满意。

## 粗拆块还要写

- **阶段划分**：把这一块按剧情阶段切开，每个阶段写起止章、主冲突（抽象地写，比如「过去的误会被第三方揭开」）、关系推进或升级曲线、换地图或换舞台的时机。有卷标题就按卷写。
- **核心设定**和**弱点**：要求同精拆，写粗一些也可以。

## 交付

最终回复直接从逐章标注的 json 代码块开始，然后是上面各节的内容，用二级标题分开，写完最后一节就结束。
