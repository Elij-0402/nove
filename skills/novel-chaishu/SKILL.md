# 拆书

**开始前先按 [SETUP.md](../novel/SETUP.md) 确认技能目录、工作区、依赖和默认规范；同一轮已完成的准备可复用，失败就停下。**

把 `对标库/<书名>/原文.txt` 拆成三份可复用的产物，存在同一目录下：`拆书报告.md`、`基线指标.md`、`风格档案.md`。只借鉴**抽象层**（结构、节奏、情绪点模型、钩子手法、人设原型、核心设定机制、文风数据），原作的情节不进入任何产物。

只需要测指标（比如审稿做基线对比）时，直接看 [METRICS.md](METRICS.md)，不走下面的流程。

## 流程

### 1. 测量和切章

在工作区根目录执行：

```
python "<技能目录>/novel-chaishu/scripts/metrics.py" "对标库/<书名>/原文.txt" -o "对标库/<书名>/指标.json" --phrases "规范/套话候选.txt"
python "<技能目录>/novel-chaishu/scripts/split.py" "对标库/<书名>/原文.txt" "对标库/<书名>/章节" -o "对标库/<书名>/分块.json"
```

- **`split.py` 把源本切成 `章节/NNNN-标题.md`**：首行是 `# 标题`，之后每行一段，所以第 N 行就是第 N−1 段。切章和去杂质的规则与 `metrics.py` 相同。输出的 `对标库/<书名>/章节/` 必须是可重新生成的专用目录：重跑会清理该目录中的旧 md，不能指向作者正文或混放其他文件的目录，也不清理其他作者目录。
- **`分块.json` 给出精拆范围和子代理分块**：`精拆` 是精拆范围（前 15 万字或前 50 章，取较少的一方），`黄金三章` 由你自己拆，`分块` 里是其余章节切好的块。
- **精拆范围单独测一份 `指标-精拆.json`**：把 `章节/` 里第 1 章到精拆末章的文件复制到一个临时目录，对这个目录跑 `metrics.py`，参数和上面相同，只把 `-o` 换成 `指标-精拆.json`。新作前期和对标比较时，用的就是这一份。
- **章数不对就停下。** 标题是「全文」，或者章数明显和源本不符，先检查源本的标题格式，再往下走。

### 2. 读文案和黄金三章

读 `原文.txt` 开头到第一章之前的书名和简介，再逐字读完黄金三章。然后定下两件事：

- **题材**：平台和细分类型，比如「晋江现言，破镜重圆加同居」。
- **情绪点类型库初版**：按这个题材归纳，不要套用固定的爽点表。言情题材的类型是心动、甜、虐、误会、误会解除、关系推进、吃醋、护短这一类；玄幻才是打脸、升级、扮猪吃虎那一类。这份初版会发给所有子代理，让大家用同一套类型名。

### 3. 并行分块

**有粗拆块（全书超过精拆范围）时，在同一条消息里为 `分块` 的每一块各派一个子代理。** 任务书是 [CHUNK-BRIEF.md](CHUNK-BRIEF.md) 的全文，后面附上：书名、题材、类型库初版、块号、类型（精拆或粗拆）、起止章和文件列表。没有粗拆块的小书，你自己按任务书把各块读完；`分块` 为空时（全书不到 4 章）跳过这一步。

子代理干活时，你按同一份任务书的精拆要求标注黄金三章，另外按 [OUTPUTS.md](OUTPUTS.md) 里的「黄金三章逐章拆解」写好这三章的拆解。

### 4. 汇总

- **把各块的逐章标注合并成 `对标库/<书名>/语义标注.json`**：一个按序号排好的数组，从第 1 章到最后一章，每章正好出现一次。缺章就把那一块重派一次。
- **新角色按人名去重**：子代理只看得到自己那一块，前面块里登场过的角色会被再记一次。每个人只保留最早那一章。
- **类型库定稿**：把子代理新增的类型并进来，同义的合并成一个，不是情绪的（比如结构手法、混进来的钩子类型名）改掉或删掉，并同步改掉标注里的类型名。
- **子代理报告的源本问题要回头核实。** 比如残留的水印，这说明 `metrics.py` 的去杂质规则有漏洞：先修脚本（见 [METRICS.md](METRICS.md) 的「测试」），再重跑第 1 步。子代理引用的行号是按旧的章节文件算的，写进产物前要重新核对。
- **语义指标用 [`semantics.py`](SEMANTICS.md) 从 `语义标注.json` 和 `指标.json` 算**：全书跑一次、精拆范围加 `--range` 再跑一次，口径见 [SEMANTICS.md](SEMANTICS.md)。不要心算。

### 5. 写产物

按 [OUTPUTS.md](OUTPUTS.md) 写三份产物。写完逐条自检：

- 情绪点类型库属于这本书的题材。
- 「弱点」每条都指到章节范围，或者某章的行号。
- 全文只讲手法、结构和功能；情节只以抽象的阶段和装置出现，黄金三章的拆解也是讲手法。
- 机械指标都能在 `指标.json` 里找到原数；语义指标都标明来源是标注统计还是判断。
- 引用原文只出现在风格档案的修辞示例里（长度限制见 [OUTPUTS.md](OUTPUTS.md)）。

**`语义标注.json` 要留着**，因为基线指标的语义部分是从它算出来的。`章节/` 和 `分块.json` 是中间产物，随时可以重新生成。
