# 角色卡模板

改自方法论报告的「角色档案」表，加了「当前状态」。设定阶段按它写 `设定/角色.md`：一个角色一张卡，二级标题写角色名，下面分「档案」「当前状态」两个三级标题；一个字段有好几条的，比如人际关系一人一条，写成子项。

字段可以增删，说明和示例可以改。「秘密」和「当前状态」一节里各字段的名字，写章回写、审稿核对时要按名字找内容，改名要连带改用到它的 skill。

## 档案

| 字段 | 内容说明 | 示例 |
|---|---|---|
| 姓名 | 角色姓名 | 李拓 |
| 定位 | 功能定位：主角、对手、助攻、读者嘴替、长辈…… | 男主 |
| 年龄 | 开篇时的年龄或外貌年龄 | 18 岁 |
| 外貌 | 让读者认出他的一两处特征，全书不变 | 左眉一道旧疤，个子比同龄人高一头 |
| 身份/背景 | 出身、经历、职业；会随剧情变的境界和职位写进当前状态 | 小村少年，父母早亡，被苍玄门收为外门弟子 |
| 性格特征 | 性格、优缺点；表层和内核不一样时两层都写 | 冲动仗义 |
| 能力/技能 | 战斗力、特殊能力、专业本事 | 精通剑术，控火能力 |
| 目标/动机 | 人物追求和目标 | 复仇、保护家人 |
| 秘密 | 瞒着谁、什么事、曝光的代价；没有写「无」 | 身负魔族血脉，瞒着师门，暴露就会被逐出山门 |
| 说话方式 | 口头禅、固定的回话、对话标签用的状态修饰、专属词汇；风格档案交给设定阶段定的写在这里 | 口头禅「怕什么」；急了就连名带姓喊师兄 |

## 当前状态

写到这一刻为止的状态。设定阶段写开篇时的，写章每写完一章回写。

| 字段 | 内容说明 | 示例 |
|---|---|---|
| 截至 | 状态更新到哪一章；设定阶段写「开篇」 | 第 12 章 |
| 境界/身份 | 修炼境界，或者职位、头衔、排名、处境 | 练气三层，外门弟子 |
| 所在地 | 人在哪，用世界观「场景」里的地名 | 苍玄门外门 |
| 持有物 | 会影响剧情的物品、钱、证据、信物 | 残缺的剑谱，三块下品灵石 |
| 伤势 | 伤、病、身体和精神状况；没有写「无」 | 左臂骨裂，未愈 |
| 人际关系 | 和主要角色现在的关系和态度，一人一条 | 师兄赵乾：表面照顾，暗中提防 |
| 知情 | 知道哪些秘密，还不知道哪些；只列会影响剧情的 | 知道师父中了毒；不知道下毒的是赵乾 |
