# 卷纲模板

照方法论报告的「章节大纲」表，前面加了「本卷」，后面加了「节奏对照」，章纲加了情绪点、对照基线、钩子、伏笔四栏。大纲阶段写 `大纲/卷纲-NN.md` 时用：「本卷」写成一行一个「- 字段：内容」，「章纲」照表头写一张表，一章一行。

栏可以增删，示例可以改。「章纲」一节的名字和「章」「概要」「情绪点」「钩子」「伏笔」五栏，写章、审稿要按名字找内容，改名要连带改用到它的 skill。

## 本卷

| 字段 | 内容说明 | 示例 |
|---|---|---|
| 卷 | 第几卷，起止章 | 第一卷，第 1–30 章 |
| 故事内时间 | 本卷从哪天到哪天 | 入门试炼到外门大比，三个月 |
| 主冲突 | 同总纲「分卷」，可以写细 | 李拓在外门站稳脚跟，被师兄处处压着 |
| 关系推进或升级 | 本卷从哪一级走到哪一级，每一级升在哪章 | 练气一层（开篇）→ 三层（第 11 章）→ 五层（第 27 章） |
| 大高潮 | 本卷的大高潮章，一章一句 | 第 2 章：夜袭中师父受伤，李拓觉醒新力；……；第 30 章：大比夺魁 |
| 换舞台 | 本卷去了哪些新地方，为什么去；不换写「无」 | 第 18 章：随师兄下山采药，为的是逼他说出师父的旧事 |

## 章纲

章号全书连续。情绪点按出现顺序写，类型名用主对标拆书报告「情绪点类型库」里的；对照基线写本章情绪点的数量和间隔、离上一个大高潮几章，各自对着哪个目标。

| 章 | 标题（可定） | 概要 | 情绪点 | 对照基线 | 钩子 | 伏笔 |
|---|---|---|---|---|---|---|
| 第 1 章 | 少年入门 | 李拓拜入苍玄门，展示天赋，结识伙伴。 | 憋屈 → 爽 → 笑点 → 危机（4） | 4 个，约 750 字一个，目标 ≤ 800；离上个大高潮 — | 悬念：师兄看他的眼神不对 | 埋 F01 |
| 第 2 章 | 杀入夜袭 | 魔煞教突袭，主角奋力抗敌，师父受伤，主角觉醒新力。 | 危机 → 虐 → 护短 → 爽（4），大高潮 | 4 个，约 750 字一个，目标 ≤ 800；首个大高潮，目标不晚于第 10 章 | 反转：救他的人是魔煞教的 | — |
| 第 3 章 | 逆转与突破 | 李拓不屈学习焚天诀，在比试中战胜大敌。 | 笑点 → 心动 → 爽 → 笑点 → 爽（5） | 5 个，约 600 字一个，目标 ≤ 800；离上个大高潮 1 章 | 情感悬停：师妹开口前收章 | 埋 F03 |

## 节奏对照

数字用 python 从章纲算出来，目标抄总纲的「节奏目标」。

| 指标 | 目标 | 本卷 | 达标 |
|---|---|---|---|
| 每章情绪点（最少 / 平均） | 至少 4 个 | 4 / 4.3 | 是 |
| 情绪点间隔（最长的一章，字一个） | ≤ 800 | 750 | 是 |
| 大高潮章 | 首个不晚于第 10 章 | 第 2、6、11、16、21、26、30 章 | 是 |
| 大高潮间隔（中位 / 最大，章） | ≤ 5 / ≤ 6 | 5 / 5 | 是 |
| 钩子覆盖率 | ≥ 0.9 | 1.0 | 是 |
| 情绪点类型配比 | 爽约 30% | 爽 32%、危机 18%、笑点 15% | 是 |

- **大高潮间隔从上一卷最后一个大高潮算起**，第 1 卷从首个大高潮算起。
- **达标只写「是」或「否」。**
- **总纲里另有的节奏目标，这里也加行对照**，偏离基线较多的类型在表后写一句为什么。
