# 写章

**开始前先按 [SETUP.md](../novel/SETUP.md) 确认技能目录、工作区、依赖和默认规范；同一轮已完成的准备可复用，失败就停下。**

写正文有四种活儿：**代写**按章纲写当前章、**收稿**收作者自己写的稿、**局部代笔**只写作者指定的一段、**卷末结算**把写完那一卷的卷摘要并入全书摘要。写出来的章正文存成 `作品/<书名>/正文/NNNN-章名.md`。

**章纲定这一章发生什么，设定和前文定什么是真的，风格档案定怎么写。** 章纲和设定、前文对不上时，照设定和前文写，停下时报给作者。

## 选模式

先看项目.md 的进度和作者的话，挑一种，别的模式的流程不套用：

- **作者要你写或重写某一章里的一段**（「这场戏帮我写」「补一段过渡」「这段重写」）→ **局部代笔**，读 [PARTIAL.md](PARTIAL.md)。只改那一段，不回写、不改进度；进度在哪一步都能做，这一条优先。
- **进度「卷末结算 / 待开始」** → **卷末结算**，读 [VOLUME-END.md](VOLUME-END.md)。
- **进度「写章 / 待开始」**，看当前章正文在不在 `正文/` 下：
  - **还不在** → **代写**，走下面 §1–§6，一次只写一章。
  - **已经在，是作者自己写的定稿** → **收稿**，见 §7。拿不准是收稿还是上次代写没写完，先问作者，不覆盖、不改。
- **进度对不上**（待审、待拍板等）又不是局部代笔 → 停下，把进度报给作者。

## 1. 找作品

- **代写和收稿只做进度是「写章 / 待开始」的作品。** 作者点了名就用那一部，进度对不上就停下，把进度报给作者。没点名，找 `作品/*/项目.md` 里处在这个进度的；有好几部就问作者。
- **写的是项目.md「当前章」那一章。** 作者要写别的章，停下告诉作者当前章是第几章：章按顺序写，每章都要审、要过关卡。
- **代写要求当前章正文还不在 `正文/` 下。** 已经在了，照「选模式」办：作者自己写的定稿走收稿（§7），上次代写没写完就问作者接着写还是重写，都不覆盖。

## 2. 读材料

**只读下面这些，按需读到节和行，不整库全读。** 上下文留给正文和前文。一边读一边记下读了哪个文件的哪一节，停下时要列给作者。

- **项目.md**：基本信息（每章目标字数、平台）和进度。
- **当前卷的 `大纲/卷纲-NN.md`**：「本卷」一节；「章纲」表里只读当前章和下一章两行。下一章那行只用来避免抢戏。
- **`大纲/伏笔表.md`** 里的这几行：当前章「伏笔」一栏点到的编号；计划回收章节是当前章的。
- **`设定/角色.md` 里出场角色的卡**：章纲概要里出场的角色，读整张卡（档案和当前状态）。只被提到名字、不出场的，不读。一次性的病人、路人不建卡，现编，记进卷摘要。
- **关系体系或力量体系**：关系体系读「关系阶梯」里主角现在那一级和下一级两行，和「规则和边界」；力量体系读「境界」里出场角色现在那一级和下一级，和「规则和代价」。
- **`设定/世界观.md`**：「用语」一节全读；「主要规则」「场景」只读这一章用到的行。
- **交办另起的文件**（比如 `设定/病例.md`）：开头的用法，和这一章用到的条目。
- **`设定/时间线.md`**：「正文」一节的最后几行，「排定的事」里这一章前后的一两行。
- **摘要**：`摘要/全书摘要.md` 和当前卷的 `摘要/卷摘要-NN.md`，有就读全文。本卷第一章还没有卷摘要。
- **前 2～3 章正文**：当前章前面最近的三章，不够三章有几章读几章。
- **`风格档案.md` 全文**，和 **`规范/AI腔清单.md` 全文**。

## 3. 写

- **章纲里的事都写到。** 概要里的事件都要发生；情绪点按章纲的顺序和个数出现；钩子落在最后一段或最后一行。伏笔一栏写「埋 Fxx」的，照伏笔表那一行埋进去，只埋不点破；写「收 Fxx」的，在这一章收。下一章章纲里的事不写。
- **细节可以加，已定的事不改。** 概要没写到的对白、动作、一次性人物，自己加。设定、前文和摘要「定下的事」里已有的事实不改。
- **开头接上一章的章末**：第一段接着上一章最后一段写。第 1 章从章纲概要的第一件事写起，不先交代背景。
- **视角照风格档案「叙述视角」。** 男主或配角的视角短切，只放在章纲写了的章。
- **风格档案一节一节落实**：句长段长、对白占比、描写和叙事的比例、常用词和修辞、该作者不用的表达。角色的口头禅、固定回话和对话标签照角色卡「说话方式」写，不给没定的角色编口头禅。
- **边写边避开 AI 腔清单。** 白名单和偶尔用里的词，一章的次数不超过清单「用法」里的折算上限。
- **真实世界的知识照设定写。** 病名、剂量、流程这类照交办文件；标【待查】的不写具体数字，绕开写。
- **字数贴着项目.md 的每章目标字数写，差不超过 ±15%。** 口径是 `metrics.py` 的字数：非空白字符，标点算在内，标题行不算。超了删，不够就补场面里的动作和对白，不注水，不加总结。
- **章名用章纲的标题。** 文件格式见 [OUTPUTS.md](OUTPUTS.md)。

## 4. 自检

1. **用指标脚本测这一章**，在工作区根目录执行，输出放系统临时目录，不放进作品库：

   ```
   python "<技能目录>/novel-chaishu/scripts/metrics.py" "作品/<书名>/正文/NNNN-章名.md" -o "<临时目录>/指标.json" --phrases "规范/套话候选.txt"
   ```

   - 字数在第 3 步的区间里。
   - 词表计数对照风格档案：白名单和偶尔用里的词不超过 AI 腔清单「用法」里的折算上限，该作者不用的表达一次都没有。
   - 对白占比、句长和段长的中位数对照风格档案，差得多就改。
2. **拿 AI 腔清单一条一条过正文**，查到的改掉。
3. **对照章纲逐项核**：事件、情绪点的顺序和个数、钩子、伏笔。

改过就重测，直到字数和词表都过了。

## 5. 回写

按 [OUTPUTS.md](OUTPUTS.md) 回写四处：角色当前状态、伏笔表、时间线的「正文」一节、当前卷的卷摘要。

- **只写正文里真的发生了的。** 章纲写了、正文没写成的，不回写。
- **回写的事实要能在正文里指出是哪一段。** 审稿会抽查。

## 6. 停下

1. **项目.md 的进度改成「写章 / 待审」**，当前卷、当前章不变。
2. **回复作者**：
   - 正文文件路径，字数和目标区间。
   - 写前读了什么：按第 2 步的顺序列文件和节。
   - 章纲怎么落的：情绪点、钩子、伏笔各一两句。
   - 回写了什么：一个文件一两行。
   - 和章纲、设定对不上的地方，照设定改了什么；没有写「无」。
   - 下一步：审稿（`/novel-shengao`）审这一章，审完停在章节关卡。

**这一轮到此结束。** 作者说要连写几章也一样：每章都要审稿、过关卡，下一章等这一章通过以后再写。

## 7. 收稿

**收稿是收作者自己写好的当前章，跑回写、送审，正文一个字不改。** 用在进度「写章 / 待开始」、当前章正文已经是作者的定稿时。和代写共用大部分流程，差别只在不写、不改。

1. **读材料**：照 §2 读那一套；另外**把作者这一章的正文全文读完**——收稿要拿它跟章纲、设定、伏笔、前文核对，也是回写的唯一依据。
2. **不写、不改正文**（跳过 §3）。正文和章纲、设定、前文对不上，或者字数超出区间、有 AI 腔——**只记下来报给作者，一个字都不动正文**。改不改由作者定。
3. **测一遍**：照 §4 第 1 步用指标脚本测这一章，字数、词表测出来报给作者；§4 的第 2、3 步（改正文、按清单改写）不做，只把发现的问题列成清单。
4. **回写**照 §5：角色当前状态、伏笔表、时间线、当前卷卷摘要，全部**以作者的正文为准**，正文里没发生的一律不回写。回写的每条都要能在正文里指出是哪一段。
5. **停下**照 §6，进度改「写章 / 待审」，当前卷、当前章不变。回复里**点明这是收稿、正文未改**，把测出来的字数、AI 腔、和章纲/设定对不上的地方一并列出交作者定夺；下一步照样是审稿（`/novel-shengao`）。
