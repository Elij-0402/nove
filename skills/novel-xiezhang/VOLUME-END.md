# 卷末结算

**把刚写完那一卷的卷摘要并入全书摘要，再把进度推进到下一卷。** 用在进度「卷末结算 / 待开始」。一次只结算当前卷。卷摘要是一章一节的近景，给写下一章用；全书摘要是一卷一节的远景，给写后面几卷、写下一卷卷纲用——这一步就是把近景压成远景，好让上下文不随章数一直涨。

卷末结算本身**不是关卡**，不用等作者拍板；做完推进状态、停下报告，由作者或总控接着调下一步。

## 1. 找作品

- **只做进度「卷末结算 / 待开始」的作品。** 作者点了名就用那一部，进度对不上就停下，把进度报给作者。没点名，找 `作品/*/项目.md` 里处在这个进度的；有好几部就问作者。
- **要结算的是「当前卷」NN 那一卷。** 核对本卷各章正文和 `摘要/卷摘要-NN.md` 都在；缺了停下报给作者，不硬结算。

## 2. 读材料

按需读，不整库全读：

- **`摘要/卷摘要-NN.md` 全文**——这是要压缩的输入。第一节和最后一节的章号就是本卷的起止章。
- **`摘要/全书摘要.md`**：有就读全文，往后追加，并照已有各卷的写法保持口径一致；第一卷结算时还没有，这次新建。
- **`大纲/伏笔表.md`**：埋在本卷、或计划在本卷回收的那些行，核对状态。
- **`大纲/总纲.md`** 的本卷、下一卷两段：本卷走完了总纲里的哪一步，下一卷要接什么。
- **`设定/角色.md`** 主要角色的「当前状态」：卷末各人停在什么位置、彼此什么关系。
- 需要时翻本卷的 `大纲/卷纲-NN.md` 的「本卷」一节，对一下这一卷的主线。

## 3. 并入全书摘要

把当前卷压成全书摘要的一节，追加进 `摘要/全书摘要.md`（第一卷结算时新建）。

- **一节的字段、取舍和篇幅照 [OUTPUTS.md](OUTPUTS.md) 的「全书摘要」**：只留跨卷还要用的，本卷内闭环的流水和一次性人物留在卷摘要里备查。
- **以正文和卷摘要为准**，写已经发生的，不写计划；和角色当前状态、伏笔表对不上的，记下来报给作者，这一步不改它们。

## 4. 核对伏笔

**只核对、上报，不改伏笔表**——伏笔表的维护是写章回写和审稿的活儿，卷末只做体检。

- **本卷该回收、卷摘要显示还没回收的**，列出来报给作者。
- **本卷埋下、要跨卷回收的**，对一下伏笔表里有没有登记计划回收章节；没登记的报给作者，交回写或审稿补。

## 5. 推进状态（项目.md）

- **不是最后一卷**：当前卷 +1，当前阶段改「卷纲」、状态改「待开始」。**当前章不动**（仍指向本卷最后一章），等下一卷卷纲过关时由 `novel-dagang` 改成下一卷第一章。
- **是最后一卷**（当前卷已是目标卷数、总纲里没有后续卷）：当前阶段改「完结」，状态「—」。
- 关卡日志不用追加（这一步不是关卡）。

## 6. 停下

回复作者：

- **全书摘要**新增了哪一卷，并入的主线和要守的账各一两句；文件路径。
- **伏笔核对结果**：本卷未回收的、需补登记的，各列出来；没有写「无」。
- **和角色状态、伏笔表对不上的地方**，怎么处理的；没有写「无」。
- **状态推进到哪**：下一卷卷纲待开始（当前卷已 +1），或全书完结。
- **下一步**：不是完结就是 `/novel-dagang` 写第 N+1 卷卷纲，会停在卷纲关卡；完结就没有下一步。
