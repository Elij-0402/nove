# 局部代笔

**只写作者指定的那一段，段外的正文逐字不动。** 作者卡文时用：「这场戏帮我写」「补一段过渡」「这段重写」。这还在作者写稿的过程里，所以**不改进度、不回写**——整章成稿后走收稿（SKILL.md §7）送审，回写留到那时候做。

## 1. 找到那一章那一段

- **哪一章**：作者点名的章，或正在写的当前章。正文文件得已经在 `作品/<书名>/正文/NNNN-章名.md` 下；不在就问作者是不是要代写整章。
- **哪一段**：作者怎么指的都认——占位符（比如正文里留了「【这里写抢救室对峙】」）、引正文的起止句、「第 X 段到第 Y 段」、「XX 那场戏」。
- **先把范围向作者复述确认**，尤其「重写」要说清替换掉从哪句到哪句；「补过渡」要说清插在哪两段之间。**范围不清就问，别猜着大改。**

## 2. 读够上下文，别整章重来

**只读写这一段用得着的**，不用把代写流程（SKILL.md §2）那整套材料全读一遍：

- **这一段所在章的正文全文**，尤其紧挨的前一段和后一段——接口靠它们对齐。
- **这一章的章纲概要**：这段对应章纲里的哪件事。
- **这段里出场角色的角色卡**：「说话方式」和「当前状态」两栏。
- **`风格档案.md` 全文**，和 **`规范/AI腔清单.md` 全文**。

## 3. 写这一段

- **接住上下文**：开头接前一段的末尾，结尾接后一段的开头，人物、时间、地点、语气和全章连上，读起来是一只手写的。
- **只做作者要的那件事**：
  - 「这场戏帮我写」→ 按章纲里这件事写，写成场面（动作、对白），别写成梗概。
  - 「补一段过渡」→ 只写衔接，把前后接上，不塞新情节、新信息。
  - 「这段重写」→ 保留这段原来要表达的事和信息，换写法；作者另有交代（改语气、改长短、改视角）就照交代来。
- **照风格档案和角色卡写，避开 AI 腔清单**，和全章一个声音。给没定过口头禅的角色不现编口头禅。
- **篇幅贴着这一段该有的长度**，不为凑字数注水，也不顺手改别处。

## 4. 落文：精确替换

- **用编辑工具替换第 1 步确认好的那段原文**，`old_string` 就是要换掉的原文、`new_string` 是新写的，段外一个字不改。补写就在指定位置插入，两侧原文原样保留。
- **改完对一遍**：除了目标范围，正文其余部分逐字未变（可以用 `git diff` 只看到这一处改动来确认）。

## 5. 停下

回复作者：

- **改了哪一段**：引头尾几个字定位，说清是重写、补写还是新写。
- **写了多少字**，接续和风格怎么照顾的一两句。
- **碰到和章纲、设定对不上的地方**，说明怎么处理的；没有写「无」。
- **提醒**：这一轮没改进度、没回写；整章写完后走收稿（`/novel-xiezhang`，见 SKILL.md §7）送审，那时才回写角色状态、伏笔、时间线、卷摘要。
