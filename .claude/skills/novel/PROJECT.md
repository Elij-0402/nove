# 项目.md 格式和状态机

`作品/<书名>/项目.md` 是一部作品唯一的进度来源。立项拍板时由 `novel-lixiang` 创建。之后每个阶段 skill 做完自己那一步，按下面的状态机改「进度」一节；每个关卡拍板后，在「关卡日志」追加一行。总控读它来汇报。

**进度只记在这里。** 产物文件在不在，只用来核对；两边对不上时以项目.md 为准，并把出入报给作者。

## 格式

```
# 《书名》

## 基本信息

- 书名：和 作品/ 下的目录名一致
- 题材：细分类型，比如「现代言情 · 破镜重圆」
- 平台：番茄、起点、晋江这类平台名
- 每章目标字数：一个整数，比如 3800
- 目标篇幅：总字数、章数、卷数，比如「约 40 万字，约 100 章，4 卷」
- 主对标：《书名》—— 借：结构、节奏、情绪点模型、钩子手法；基线指标以它为准
- 辅助对标：《书名》—— 借：开局节奏；没有就写「无」

## 进度

- 当前阶段：设定
- 状态：待开始
- 当前卷：—
- 当前章：—
- 备注：可选，一句话说明现在卡在哪

## 审稿设置

- 停顿频率：1 章
- 全审间隔：5 章（前 3 章每章都全审）

## 立项结论

### 一句话卖点

### 超越点

### 差异清单

## 关卡日志

| 日期 | 关卡 | 决定 | 理由 |
|---|---|---|---|
```

- **字段名照抄，一个字都不改。** 各个 skill 按字段名找值。值可以由作者直接改，比如放宽停顿频率。
- **平台决定审稿用哪份读者画像，每章目标字数是写章和审稿查字数的基准。**
- **主对标的借鉴项取拍板方案差异清单里标「借」的维度。** 基线指标只认主对标，辅助对标只贡献它的借鉴项。
- **当前卷、当前章写数字，还没到卷纲、写章阶段时写「—」。** 当前章是全书连续的章序号，和 `正文/NNNN-章名.md` 的编号一致，指正在处理的那一章。
- **停顿频率是每写完几章停一次章节关卡**，默认 1。**全审间隔是每隔几章做一次全审**，默认 5；前 3 章不管间隔，每章都全审。
- **立项结论是这部作品的方向**：拍板方案的一句话卖点、超越点、差异清单，合并或改过的写最终版本。后面的阶段以它为准。

## 状态机

`拆书 → 立项★ → 设定 → 总纲★ → 卷纲★ → 写章（每章★）→ 卷末结算 → 下一卷卷纲★ …`

★ 是关卡：停下来，由作者拍板。拆书和立项发生在项目.md 出现之前：拆书产物在对标库里，等拍板的立项方案放在 `作品/立项方案-<主对标>.md`。项目.md 一创建，就处于「设定 / 待开始」。

| 当前阶段 | 状态 | 下一步 | 做完改成 |
|---|---|---|---|
| 设定 | 待开始 | `novel-sheding` 生成设定 | 总纲 / 待开始 |
| 总纲 | 待开始 | `novel-dagang` 写总纲，做原创性自检 | 总纲 / 待拍板 |
| 总纲 | 待拍板 ★ | 作者看 `大纲/总纲.md` 拍板 | 通过：卷纲 / 待开始，当前卷 1 |
| 卷纲 | 待开始 | `novel-dagang` 写当前卷的卷纲和章纲，做原创性自检 | 卷纲 / 待拍板 |
| 卷纲 | 待拍板 ★ | 作者看 `大纲/卷纲-NN.md` 拍板 | 通过：写章 / 待开始，当前章是本卷第一章 |
| 写章 | 待开始 | `novel-xiezhang` 写当前章，或者收作者自己写的稿 | 写章 / 待审 |
| 写章 | 待审 | `novel-shengao` 审当前章 | 写章 / 待拍板 |
| 写章 | 待拍板 ★ | 作者看当前章的正文和审稿报告拍板 | 通过：当前章 +1，写章 / 待开始；刚通过的是本卷最后一章：卷末结算 / 待开始 |
| 卷末结算 | 待开始 | `novel-xiezhang` 把卷摘要并入全书摘要 | 当前卷 +1，卷纲 / 待开始；全书写完：完结 |
| 完结 | — | 无 | — |

- **关卡没通过就留在原状态**，按作者的意见改完，再请作者拍板。
- **停顿频率大于 1 时，没到停顿点的章不停。** 审完直接当前章 +1，改成「写章 / 待开始」。

## 关卡日志

- **每次拍板追加一行，旧行不动。** 日期写 YYYY-MM-DD，关卡写立项、总纲、第 N 卷卷纲、第 N 章。
- **决定只写一两句**：作者选了什么、通过还是退回、要改什么。细节留在产物里，这里写去哪看。
- **理由写作者的原话。** 作者没给理由就写「作者未说明」，不替作者补。
