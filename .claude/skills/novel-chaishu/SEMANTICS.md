# 语义指标脚本

`scripts/semantics.py` 是拆书和审稿共用的语义尺子：输入一份逐章语义标注和一份机械指标 JSON，输出一份确定性的语义指标 JSON。判断（逐章标注）由 Claude 产出，口径见 [CHUNK-BRIEF.md](CHUNK-BRIEF.md) 的「逐章标注」；本脚本只做算术，是这套语义口径的唯一真源。是 [metrics.py](METRICS.md)（机械指标）的语义侧镜像。

## 运行

在工作区根目录执行：

```
python .claude/skills/novel-chaishu/scripts/semantics.py 对标库/<书名>/语义标注.json --metrics 对标库/<书名>/指标.json -o 对标库/<书名>/语义指标.json
python .claude/skills/novel-chaishu/scripts/semantics.py <语义标注.json> --metrics <指标.json> --range 1-37 -o <语义指标-精拆.json>
```

- **始终用 `-o` 写文件。** 和 metrics.py 同理，PowerShell 的 `>` 重定向会把 UTF-8 转坏。
- **`--range 起-止`（含两端）只算这段章号**，字数也按 `指标.json` 里这些章的 `字数` 求和。不给 `--range` 就是全书。「精拆范围 / 全书」两列就是同一份 `语义标注.json` 跑两次、`--range` 换一下。

## 输入

- **`语义标注.json`**：一个按序号排好的数组，每章一条 `{序号, 情绪点[], 钩子, 大高潮, 新角色[], 高光[]}`，schema 与口径都以 [CHUNK-BRIEF.md](CHUNK-BRIEF.md) 为准。拆书汇总时落地在 `对标库/<书>/语义标注.json`；全审时由子代理把窗口标注写成一份临时的同格式文件。
- **`--metrics 指标.json`**：metrics.py 的输出，只用来取每章 `字数`（`章节[].字数`）。标注里的序号在 `指标.json` 里找不到字数就报错。

## 口径

- **情绪点密度每万字** = 总数 ÷ 字数 × 10000；**每章均** = 总数 ÷ 章数；**间隔字数** = 字数 ÷ 总数（总数为 0 时是 `null`）。
- **最长空窗章数** = 连续「情绪点为空」的章的最长游程。
- **类型占比** = 各类型次数 ÷ 总数，按次数降序、同次数按名字升序排列。
- **大高潮**：`章号` 是标了 `true` 的序号；`间隔中位`、`间隔最大` 是相邻大高潮序号差（中位用最近秩法，和 metrics.py 一致）；不足两个大高潮时间隔为 `null`，一个都没有时 `首个章号` 也是 `null`。
- **钩子覆盖率** = 非「平收」的章数 ÷ 章数；`类型分布` 是各钩子次数。
- **新角色每10章** = 新角色总数 ÷ 章数 × 10。
- **主角高光覆盖率** = 有高光的章数 ÷ 章数；间隔同大高潮；`分列` 按「男主 / 女主 / 主角」各给章数、覆盖率、间隔。
- **除法分母为 0 一律给 0.0；间隔和首个算不出时给 `null`**，读者据此写「暂缺」，与真实的 0（如覆盖率确实为 0）区分开。

## 输出

```
{
  "范围": {"起", "止", "章数", "字数"},              ← 起/止 不给 --range 时为 null
  "情绪点": {"总数", "密度每万字", "每章均", "间隔字数", "最长空窗章数", "类型占比": {类型: 占比}},
  "大高潮": {"计数", "章号": [...], "首个章号", "间隔中位", "间隔最大"},
  "钩子": {"覆盖率", "类型分布": {钩子: 次数}},
  "新角色": {"计数", "每10章"},
  "主角高光": {"覆盖率", "间隔中位", "间隔最大",
             "分列": {"男主": {"章数", "覆盖率", "间隔中位", "间隔最大"}, "女主": {...}, "主角": {...}}}
}
```

- **同一输入永远得到逐字节相同的输出。** 占比和分布的顺序也是确定的（次数降序、名字升序）。
- **新作和对标比较看占比、密度、每万字、覆盖率这些比例量**，别直接比总次数。
