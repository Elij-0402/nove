# 指标脚本

`scripts/metrics.py` 是拆书和审稿共用的尺子：输入一本 txt、一个章节 md 目录或单个章节 md，输出一份确定性的 JSON。只测机械指标；情绪点、钩子、高光这类语义的**判断**由 Claude 产出、**算术**在 [semantics.py](SEMANTICS.md)，都不在本脚本里。

## 运行

在工作区根目录执行：

```
python .claude/skills/novel-chaishu/scripts/metrics.py 对标库/<书名>/原文.txt -o 对标库/<书名>/指标.json
python .claude/skills/novel-chaishu/scripts/metrics.py 作品/<书名>/正文 -o <输出.json>
python .claude/skills/novel-chaishu/scripts/metrics.py 作品/<书名>/正文/0001-章名.md -o <输出.json>
```

- **始终用 `-o` 写文件。** PowerShell 的 `>` 重定向会把 UTF-8 转成别的编码，JSON 就坏了。
- **测新作的某个窗口（比如最近 5 章），先把这几章复制到一个临时目录再测。** 脚本总是测整个目录。
- **要数特定的词，用 `--phrases 词表.txt`。** 词表每行一个词，空行和 `#` 开头的行跳过。拆书用它配合 [套话候选.txt](套话候选.txt) 找出白名单和不用的表达。

## 输入

- **txt 按标题行切章。** 编码自动识别（UTF-8、UTF-8 BOM、GBK/GB18030）。识别的标题：`第N章/回/节`（阿拉伯或中文数字，章名可有可无）、番外、楔子、尾声等关键字开头的短行，可带「正文 」「【」或同一行的卷号前缀。`第N卷/部/集` 是卷标题，记到其后各章的「卷」字段。完整规则见脚本里的 `CHAPTER_RE`、`VOLUME_RE`。
- **第一个章标题之前的书名、简介丢弃。** 一个章标题都识别不到时，整篇算一章，标题为「全文」；拿到这种结果先检查源本的标题格式。
- **章节 md 每个文件算一章。** 目录按文件名排序，所以编号要补零（`0001-章名.md`）。章名取首行 `#` 标题，没有就取文件名去掉编号。
- **杂质不参与统计。** 包括空行、整行只有符号的分隔线（含章内的场景分隔「-」「※※※」）、「（本章完）」、含网址或下载站声明用语的行，以及「作者有话要说」到下一个标题之间的作者留言。

## 口径

- **字数是非空白字符数，标点算在内。** 句长、段长、章字数都用这个口径。
- **段落是去掉杂质后的每个非空行。**
- **对白占比 = 引号内的非空白字数（不含引号本身）÷ 字数。** 引号包括 “” 「」 『』 和成对的直引号 "。跨段未闭合的引号在段末截止。
- **句子按 `。！？!?…` 切，紧跟的收引号归前句。** 只有标点的碎片（如「……」）不算句子。
- **分位数用最近秩法。** 结果都是实际出现过的长度值。
- **词表计数是去杂质后正文里的出现次数**，同一段里不重叠地数。
- **高频词是汉字 2～4 字片段，不是分词结果。** 几乎总出现在更长片段里的短片段会被吸收（「以凡」并入「温以凡」），虚词和「的」「了」之类的粘连片段被滤掉，取出现 ≥2 次的前 100 个。结果仍会夹杂少量非词片段，引用时自己判断。

## 输出

```
{
  "全书": {
    "章数", "字数", "对白占比",
    "章字数统计": 长度统计,
    "句长统计": 长度统计（含分布）, "段长统计": 长度统计（含分布）,
    "高频词": [{"词", "次数", "每万字"}],
    "词表计数": [{"词", "次数", "每万字"}]   ← 只在给了 --phrases 时出现，顺序同词表
  },
  "章节": [
    {"序号", "标题", "卷", "字数", "对白占比", "句长统计", "段长统计"}
  ]
}
```

- **长度统计**：`数量`、`平均`、`最小`、`P25`、`中位数`、`P75`、`P90`、`最大`。
- **分布**：各长度区间所占比例，区间名就是 JSON 里的键。
- **新作和对标比较时看比例和每万字频次。** 两边体量不同，直接比次数没有意义。
