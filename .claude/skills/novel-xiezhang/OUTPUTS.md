# 写章产物格式

## 正文

`作品/<书名>/正文/NNNN-章名.md`：NNNN 是当前章补零到四位，章名是章纲的标题。

```
# 第 N 章 章名

一段一行，段与段之间空一行。
```

- **文件里只有正文。** 不写作者的话、章纲备注、字数。
- **场景切换和视角短切照风格档案的写法**，比如单独一行的「……」，或者「另一边」开头的一段。
- **文件名按补零的编号排序**，指标脚本测整个 `正文/` 目录时按这个顺序读。

## 角色当前状态

`设定/角色.md` 里每张卡的「当前状态」一节。

- **这一章出场的角色，「截至」都改成「第 N 章」，其余字段变了的才改。** 没出场的不动，被提到名字也不动。
- **只改「当前状态」，「档案」不动。** 正文和档案对不上，报给作者。
- **人际关系**：关系升了一级，写新的级名；态度变了，改那一条，写成现在的样子，不写过程。
- **知情**：谁在这一章知道了什么，加上；谁误会了什么，写成「以为……」。
- **一次性人物不建卡**，记进卷摘要的「定下的事」。

## 伏笔表

`大纲/伏笔表.md`。

- **章纲写「埋 Fxx」、正文埋了**：状态改「已埋」；埋在别的章了，埋设章节改成实际的章。
- **章纲写「收 Fxx」、正文收了**：状态改「已回收」。
- **章纲要埋或要收、正文没写成**：状态不动，停下时报给作者。
- **正文里多出来、以后要回收的东西**：加一行，编号接着往下排，计划回收章节写到卷，状态「已埋」，停下时报给作者。

## 时间线

`设定/时间线.md` 的「正文」一节，一章追加一行：

| 章 | 故事内时间 | 事件 |
|---|---|---|
| 第 N 章 | 写到日；能写到时刻的写时刻 | 一两句，只写以后会被引用的事 |

## 卷摘要

`摘要/卷摘要-NN.md`，NN 是两位卷号。本卷第一章写完时建文件，之后每章追加一节。

```
# 《书名》第 N 卷摘要

## 第 N 章 章名

- 时间：故事内的日期和时段
- 经过：三到五句，谁做了什么，结果怎样
- 定下的事：正文里新出现、以后要守的细节：一次性人物的名字和身份，说出口的关键台词，数字，谁欠谁什么
- 章末：停在哪一刻，下一章从这里接
```

- **标题的卷号用中文数字，和卷纲一致**，比如「第一卷摘要」。
- **写正文里发生的，不写章纲里计划的。**
- **定下的事一条一句**，没有写「无」。后面写章和审稿都拿它核对前文。
