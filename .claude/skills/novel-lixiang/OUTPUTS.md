# 立项产物格式

## 立项方案

方案文件的格式。三个方案用同一套小节，方便作者横着比。

```
# 立项方案：对标《主对标》

日期：YYYY-MM-DD
主对标：《书名》（题材）
辅助对标：《书名》借「借鉴项」；没有写「无」
作者要求：作者调用时提的要求；没有写「无」

## 方案一：《暂定书名》（贴近）

**一句话卖点**：只写一句。

- 题材：细分类型
- 目标平台：平台名，一句话说为什么是它
- 篇幅：总字数、章数、卷数；每章字数和依据

### 超越点
2–3 条，第一条是主打。每条写：弱点 N「标题」→ 新作怎么做，靠什么机制。

### 差异清单
| 维度 | 对标 | 新作 | 借 / 改 |
|---|---|---|---|
| 爆点机制 | | | |
| 核心关系 | | | |
| 核心装置 | | | |
| 主角人设 | | | |
| 配角和对手 | | | |
| 舞台和职业 | | | |
| 情绪点配比 | | | |
| 结构和节奏 | | | |
| 钩子手法 | | | |
| 文风 | | | |

### 辅助对标怎么用
每个借鉴项落在新作的哪里。没有辅助对标就删掉这一节。

### 主要风险
一两句。

## 方案二：《暂定书名》（居中）
## 方案三：《暂定书名》（最远）

## 比较
| | 方案一 | 方案二 | 方案三 |
|---|---|---|---|
| 离对标 | 贴近 | 居中 | 最远 |
| 一句话卖点 | | | |
| 核心装置 | | | |
| 主打超越点 | | | |
| 平台 / 篇幅 | | | |
| 主要风险 | | | |
```

- **「对标」一栏写抽象层**，用拆书报告里的说法，不复述原作情节。
- **「借 / 改」只填一个字。** 借：新作保留对标这一项的功能或数据，形态重新设计。改：连功能也换掉。不管借还是改，「新作」一栏都写出新作自己的具体形态。
- **推荐只在作者请你帮忙选时才写**，放在「比较」之后，标题写「推荐」：推荐哪个方案、改哪几处、理由、反对意见。
- **最终方案追加在文件末尾**，只在作者要求合并或修改时才有。标题写「最终方案：《书名》」，下一行写它由哪几个方案怎么合成、改了什么，其余小节同单个方案。

## 项目风格档案

`作品/<书名>/风格档案.md`，从主对标的风格档案派生。辅助对标借的是文风时，把它的叙述视角、标志性修辞这类【判断】项作为【调整】搬进来，注明出处；【脚本】数字一律用主对标的，尺子只有一把。

```
# 《书名》风格档案

派生自：对标库/<主对标>/风格档案.md
【继承】照抄对标的原值；【调整】写明对标原值、新作目标和理由。

## 叙述视角
## 句长和段长
## 对白
## 描写与叙事的比例
## 高频词和口头禅
## 标志性修辞
## 白名单
## 偶尔用
## 该作者不用的表达
```

- **节标题和对标的风格档案完全相同**，写章和审稿按节标题找内容。
- **每一条都标【继承】或【调整】。** 一节里全是继承，就在节标题下面第一行标一次【继承】，节标题本身不动。
- **【继承】照抄原值和原来的【脚本】【判断】来源标记。** 只有原文短例例外：修辞只抄特征和用法，例子为新作另写，或者不写。
- **【调整】写三样**：对标原值、新作目标、理由。理由出自拍板方案，比如平台读者、超越点、视角或人设的改动。对标原值里带原作人名的，换成功能定位，比如「实习生对女主的称呼」。
- **原作角色的口头禅不继承。** 这一条标【调整】，写「设定阶段按新角色另定」。
- **绑定原作角色的修辞，换成新作角色对应的写法**，比如某个角色专属的反问句式、专属词汇群，标【调整】。
- **白名单、偶尔用、该作者不用的表达默认继承。** 审稿查 AI 腔要用。
- **拍板方案里跟文风有关的超越点，落到对应的节里**，标【调整】。比如对标弱点里的「叙述者跳出来预告」，落到「该作者不用的表达」。
